## 2026-11-01 客户端与服务器命令路由修复

原实现只查询 NeoForge 本地客户端调度器，导致原版服务器命令 `/help` 和 `/msg @s 111` 在序列预检查时被拒绝。
现在本地已注册的命令按根名称优先在本地检查、执行，其余通过原版 `ClientPacketListener.sendCommand` 发送，以保留消息参数签名与聊天确认机制。
服务器命令只检查非空和连接可用；不依赖可能不完整的服务端命令树，也不在本地执行服务端树中的占位处理器。

- Minecraft 1.21.1 / NeoForge 21.1.172 / Java 21.0.11，独立开发客户端与内置服务器。
- 94 项客户端检查通过，其中保留此前 77 项界面、按键和序列检查，新增 17 项命令路由检查。
- 真实序列发送 `/help`、`/msg @s 111`，从服务端 CommandEvent 确认原始文本到达，并检查客户端聊天栏中的帮助与私聊反馈；没有直接调用服务端命令执行器代替发送命令。
- 客户端与服务端注册同名测试命令，确认客户端优先且服务端未执行。
- 服务端注册、但没有向客户端公开的测试命令仍能正常到达并执行。
- 本地命令参数错误仍在预检查阶段拒绝；本地命令失败与命令打开界面时仍取消剩余步骤。
- 服务端返回失败或未知命令反馈时，聊天栏正常显示错误，后续步骤继续。
- 普通构建与 34 项单元测试通过；英文、简体中文、繁体中文提示均已更新。

复现：

```powershell
.\gradlew.bat runClient -Psmoke -PsmokeDir=build/command-routing-smoke-run --offline
.\gradlew.bat clean build --offline
```

原始结果：[94 项客户端检查](command-routing-checks.txt)、[客户端日志](command-routing-client.log)。
`/msg @s 111` 在允许选择器的测试环境执行；服务器权限与正常聊天栏一致。未测试第三方多人服务器的插件组合或在线账号的安全聊天策略；发送使用原版接口。

## 2026-10-30 按键兼容修复

GestureKeys 现在向选定的 `KeyMapping` 实例派发按下与释放，兼容通过覆写 `setDown` / `isDown` 实现的动作。
手势执行期间只豁免目标映射的组合修饰键要求，保留其冲突上下文；不改变保存的键位、物理修饰键或玩家下蹲状态。

- 普通构建与单元测试：Minecraft 1.21.1 / NeoForge 21.1.172，26 项单元测试通过。
- 客户端回归：Minecraft 1.21.1 / NeoForge 21.1.234 / 用户提供的 Mekanism 10.7.19.85，57 项检查全部通过。
- 新增检查覆盖未绑定实体键的 Ctrl/Shift 动作、绕过父类 `isDown` 的子类回调、单击/定时释放、重复触发、同键隔离、物理释放与虚拟按住重叠、扫描码物理状态、失焦释放，以及原版切换键行为。
- Mekanism 使用喷气背包与自由奔跑靴验证：通过动作执行器触发真实模式切换包，服务端模式依次为 `NORMAL → HOVER → VECTOR` 和 `NORMAL → SAFETY → DISABLED`；首次变化同步回客户端。测试没有直接调用模式切换 API。
- 测试中将胸甲映射设为 Ctrl + 未绑定、脚部映射设为 Shift + 未绑定，执行时无需按住实体修饰键。

原始检查结果：[按键兼容回归](input-compatibility-checks.txt)。

复现：将 Mekanism JAR 放入独立测试目录 `run-smoke/mods`，运行：

```powershell
.\gradlew.bat -Psmoke '-Pneo_version=21.1.234' runClient
```

不放入 Mekanism 时会跳过该模组的专属检查，仍执行通用按键回归。
测试程序恢复创造背包的客户端菜单状态后再验证装备同步，避免 UI 检查残留菜单导致槽位更新被错误应用。

本次 21.1.233 的 Maven 依赖下载超时，因此实际运行采用本机缓存的 21.1.234；未改动工程的默认版本或最低版本要求，未修改用户游戏实例。

## 性能

同一开发客户端、同一场景；绘制八个面板和一条轨迹，比较更新前渲染器与新渲染器。每种模式预热 35 帧后采样 80 帧，GPU 使用异步 GL_TIME_ELAPSED 查询。下面为 1920×1080 结果，单位 ms。

| 模式 | CPU 中位 | GPU 中位 | GPU P95 |
| --- | ---: | ---: | ---: |
| 原液态玻璃，80 点 | 0.3938 | 0.5898 | 1.1397 |
| 新液态玻璃，80 点 | 0.3424 | 0.2755 | 0.7332 |
| 磨砂玻璃，80 点 | 0.2977 | 0.2478 | 0.8632 |
| 玻璃拟态，80 点 | 0.2985 | 0.2632 | 0.9267 |
| 亚克力，80 点 | 0.3099 | 0.2744 | 0.9370 |
| 云母，80 点 | 0.2956 | 0.2877 | 0.8018 |
| 烟熏玻璃，80 点 | 0.2922 | 0.3031 | 1.0076 |
| 渐变玻璃，80 点 | 0.2991 | 0.3215 | 1.0281 |
| 极光玻璃，80 点 | 0.2900 | 0.3338 | 1.1244 |
| 水晶玻璃，80 点 | 0.2925 | 0.3482 | 1.0742 |
| 关闭玻璃 Shader，80 点 | 0.7402 | 0.2345 | 1.1162 |
| 原液态玻璃，4096 点 | 7.6534 | 24.5432 | 29.0703 |
| 新液态玻璃，4096 点 | 1.8071 | 0.5560 | 1.1776 |

这测量的是模组绘制范围，不含世界渲染和完整游戏帧耗时，也不构成其他机器的 FPS 保证。关闭玻璃 Shader 时圆角控件采用 CPU 几何绘制，CPU 时间不一定更低。半分辨率双通道模糊、轨迹覆盖合批与局部合成降低了该场景的开销；颜色和风格切换复用已有渲染目标。
